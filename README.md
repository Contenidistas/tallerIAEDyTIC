# Desafío Java · Métodos con ArrayList

Objeto de Aprendizaje web autocontenido para Programación I — INET 2026.

## Uso

1. Abrir `index.html` en un navegador moderno.
2. Ingresar el nombre del estudiante.
3. Resolver los 6 desafíos en orden.
4. Al finalizar, el recurso asigna de forma aleatoria y estable un desafío de transferencia para resolver en la computadora y entregar por CREA.

## Archivos

- `index.html`: estructura del OA.
- `styles.css`: interfaz con estética de consola.
- `script.js`: desafíos, validación, progreso local y asignación final.

## Privacidad

El nombre, el progreso y la asignación final se almacenan solo mediante `localStorage` del navegador. No existen llamadas a APIs ni servicios externos.

## Declaratoria de IA

El recurso incluye dentro de la interfaz una declaratoria de uso de IA generativa de OpenAI (ChatGPT) en tareas de ideación, redacción, diseño y asistencia de programación. La selección, revisión, adecuación didáctica y responsabilidad académica final corresponden al Prof. Santiago Hernández.
